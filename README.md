# سوق الغنم (Souq Al-Ghanam)

أكبر منصة وسوق إلكتروني موثوق لتجارة الأغنام والماعز في المملكة العربية السعودية، مبني باستخدام React 19 و Vite و TypeScript و Tailwind CSS.

## المميزات الرئيسية
- **فيديو بانر تفاعلي (Video Hero Banner)** في الصفحة الرئيسية مع تحكم بالصوت والتشغيل.
- **بانر احترافي مخصص لكل صفحة (Page Banner)** مع مسار التصفح (Breadcrumbs) ووسوم المزايا.
- **قالب موحّد واحترافي لبطاقات الإعلانات (Branded Ad Template Frame)** يعرض شارات السلالة، الوزن، العمر، المنطقة، وشارة التوثيق مدمجة بداخل إطار الصورة مباشرة.
- **تصفح الإعلانات وتصفية متقدمة** (السلالة، العمر، الوزن، السعر، المنطقة، التوثيق، والقرون) مع فرز فوري.
- **صفحة تفاصيل الإعلان** مع مقارنة السعر بالمتوسط الفعلي للسوق، كشف رقم الجوال، إرسال رسائل للبائع، والإبلاغ.
- **إضافة إعلان جديد** مع معاينة فورية في القالب المعتمد وحفظ في الذاكرة المحلية (localStorage).
- **مؤشر أسعار تفاعلي (Price Trends Chart)** برسم بياني متعدد السلالات على مدار 8 أشهر وتحليلات موسمية.
- **حاسبة الولائم والعزائم** لحساب عدد الرؤوس واللحم الصافي والتكلفة بالريال السعودي.
- **قائمة فحص المشتري (8 بنود)** مع حلقة تقدم بيانية تفاعلية (SVG Circular Progress Ring).
- **مقارنة الإعلانات جنباً إلى جنب** لما يصل إلى 3 رؤوس مع تحديد الأفضل في كل معيار.
- **دليل السلالات المفصل** (نعيمي، حري، نجدي، سواكني) بمؤشرات قياس دقيقة.
- **المقالات والنصائح وقارئ الأدلة** لتقدير العمر من الأسنان وإرشادات الرعاية والنقل.
- **شراء حسب المناسبة** (عقيقة، زواج، عزيمة، مزرعة وتربية).
- **خدمات النقل والأعلاف والبيطرة** مع نموذج طلب فوري.
- **الوضع الداكن والفاتح** مع حفظ التفضيل تلقائياً.

## التشغيل والتطوير
```bash
npm install
npm run dev
```

يعمل خادم التطوير على المنفذ `3000` على العنوان `http://0.0.0.0:3000`.
